# 🌸 Mother's Day Special Animation Wish (Premium Edition)

This is a cinematic, high-end web experience designed for Mother's Day. It features gold particle effects, smooth GSAP animations, and a responsive gallery.

## 🚀 How to Customize for Clients

All customization is done in `src/config.js`. You don't need to touch the main code.

### 1. Change Images
- Replace `heroImage` with the URL of the client's mother's photo.
- Add client-specific memories in the `galleryImages` array.

### 2. Personalize Text
- Update `clientName` to your brand or the client's name.
- Change `messages` (intro, hero, wish) to match the client's preference.

### 3. Change Colors
- Update the `colors` object to change the theme (e.g., Rose Gold, Silver, or Classic Pink).

## 🛠️ Deployment
1. Run `npm install`
2. Run `npm run build`
3. Upload the contents of the `dist` folder to any hosting (Netlify, Vercel, or client's server).
